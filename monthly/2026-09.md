## 🎓 Worth Remembering Forever

- [ ] **AI agents are more valuable when paired with focused skills** — Reusable agents become practical when their skills are aligned with specific development and testing workflows.

- [ ] **Reusable development support can extend beyond one story** — Agents and skills created for one toolkit can support future implementation and testing work as well.

- [ ] **Focused testing creates a clearer path to resolution** — Record each discovered issue separately so the complete issue list and follow-up work remain easy to track.

- [ ] **Shared environment changes require careful verification** — URL migrations and release deployments can affect multiple environments, so each target environment should be checked deliberately.

- [ ] **Release work is a complete workflow** — Creating the artifact, deploying it to the target environment, and testing the deployed changes are all important parts of the release process.

- [ ] **Small, independently merged stories make toolkit work easier to manage** — Component work can be delivered incrementally while reusable development support continues to grow.

- [ ] **Shared toolkits benefit from continuous component expansion** — Focused additions across React and Angular components steadily increase the value of the toolkit for future work.
